# Messages

Source of truth: `proto/mori.proto:15`. Rust types are generated by
`tonic_build` (`build.rs:1`); internal twins live in `src/bot_state.rs:44`,
`src/bot_manager.rs:25`, `src/items.rs`.

## Conventions

- `BotRef{bot_id}` (`proto/mori.proto:19`) is **required** on every per-bot
  call. Proto3 cannot express required, so the server enforces it in
  `bot_ref()` (`src/grpc/service.rs:58`): absent → `INVALID_ARGUMENT`.
- `has_proxy` (`SpawnBotRequest:36`, `SpawnLtokenRequest:42`) and
  `has_pass` (`EnterRequest:219`) are explicit presence flags — a proto3
  workaround so "empty string" stays distinguishable from "unset". Proxy is
  parsed only when the flag is true (`src/grpc/service.rs:485`).
- `oneof key` (`GetPlayerRequest:323`, `GetItemInfoRequest:356`): exactly one
  arm. `GetPlayer` name match is ASCII case-insensitive
  (`src/grpc/service.rs:1218`); `GetItemInfo` tries numeric-name → ID first
  (`src/grpc/service.rs:1300`).
- Integer narrowing is lossy by design: `u16` game IDs ride as `uint32`,
  `count: u8` as `uint32`, delays as `uint64`. Out-of-range inputs are rejected
  (`SetCollectRange`, `WalkTo`) or clamped (`SetCollectConfig` blacklist,
  `ListItems` paging) — see `service.md`.
- `tile_type` is a `Debug`-formatted string (`format!("{:?}", …)`,
  `src/grpc/service.rs:184`), e.g. `"Basic"`, not the structured Lua
  `getExtra()` table.

## Manager

- `SpawnBotRequest{username,password,proxy,has_proxy}`, `SpawnLtokenRequest{ltoken,…}`
  → `SpawnBotResponse{bot_id}`. IDs are `BotManager::next_id` monotonically
  increasing from 0 (`src/bot_manager.rs:19`).
- `ProxyConfig{host,port,username,password}` (`proto/mori.proto:23`): empty
  user/pass means anonymous. `host` may be IP or DNS (fallback resolve in
  `parse_proxy`, `src/grpc/service.rs:232`).
- `BotInfo{bot_id,username,status,world,pos_x,pos_y,gems,ping_ms}`
  (`proto/mori.proto:49`) ← `BotManager::BotInfo` (`src/bot_manager.rs:25`).
  `status` is the `Display` string (`connecting|connected|in_game|…`,
  `src/bot_state.rs:28`); `world` is `world_name` (empty = none).
- `ListBotsResponse{bots}`; `Empty{}` takes the place of `()`.

## State snapshots

- `BotState` (`proto/mori.proto:120` ← `src/bot_state.rs:117`): status,
  username/mac, `world_name`, `pos_x/pos_y` (tile coords, pixels ÷ 32),
  `world_width/height`, `objects`, `players`, `inventory`, `inventory_size`
  (max slots from `SendInventoryState`), `gems`, `console` (tail log),
  `ping_ms` (ENet RTT), `config`. `track_info` is intentionally **not**
  exposed (only via `TrackInfoEvent`).
- `WorldObject{uid,item_id,x,y,count}` — `x/y` pixels here (unlike tiles).
- `PlayerInfo{net_id,name,pos_x,pos_y,country}` — tile coords.
- `TileInfo{x,y,fg_item_id,bg_item_id,flags,tile_type}` — absolute coords;
  `flags` is the raw `u16` bitmask (see `DOCS.md` TileFlags table).
- `InvSlot{item_id,amount,is_active,action_type}`.
- `BotConfig{auto_collect,collect_radius_tiles,collect_blacklist,ignore_gems,ignore_essences,auto_leave_on_mod,auto_ban,collect_path_check,auto_reconnect,delays}`
  (`proto/mori.proto:107`): defaults `auto_collect=true, radius=3 tiles,
  path_check=true, auto_reconnect=true` (`src/bot_state.rs:160`).
- `BotDelays{place_ms,walk_ms,twofa_secs,server_overload_secs,too_many_logins_secs,maintenance_secs}`
  defaults 500/500 ms + 120/30/5/600 s (`src/bot_state.rs:103`).

Query aggregates:

- `WorldResponse{name,width,height,tiles,objects,players}` — `tiles` is the
  **full** row-major tile list; expensive, poll sparingly.
- `InventoryResponse{size,gems,items}`; `PlayersResponse{players}`;
  `LocalPlayer{net_id=0,username,pos_x,pos_y,mac}`; `PingResponse{ping_ms}`;
  `BoolResponse{value}`.
- `ItemInfo` (`proto/mori.proto:154` ← `src/items.rs`): id/name/action,
  collision/clothing/rarity/grow/drop, texture fields, `seed_color` (= base),
  `seed_overlay_color` (= overlay), `strength = block_health / 6`.
- `ListItemsRequest{query,page,page_size}` → clamps `page ≥ 1`,
  `1 ≤ page_size ≤ 200`; `ListItemsResponse{items,total,page,page_size}`.

## Action / query shapes

- Offsets (relative to bot tile): `TileActionRequest{bot,x,y}`,
  `PlaceRequest{+item_id}`, `MoveRequest{bot,x,y}` (relative).
- Absolute: `MoveToRequest{bot,x,y}` (`MoveTo`/`WalkTo`/`FindPath` share it),
  `GetTileRequest{bot,x,y}`, `IsInTileRequest{bot,x,y}`.
- Inventory: `InventoryActionRequest{bot,item_id,count}`,
  `ItemRequest{bot,item_id}`, `WrenchPlayerRequest{bot,net_id}`,
  `BuyRequest{bot,pack_id}`, `EnterRequest{bot,pass,has_pass}`.
- Scalars: `SetBoolRequest{bot,enabled}`, `SetUintRequest{bot,value}`,
  `SetDelaysRequest{bot,delays}`, `SetCollectConfigRequest{bot,radius_tiles,blacklist}`,
  `SetMacRequest`, `SetDirectionRequest{bot,facing_left}`,
  `SayRequest{bot,text}`, `WarpRequest{bot,name,id}`,
  `CollectRequest{bot,range,interval_ms}`, `CollectObjectRequest{bot,oid,range}`,
  `SendPacketRequest{bot,packet_type,text}`,
  `SendRawRequest{bot,packet: GameUpdatePacket}`,
  `RunScriptRequest{bot,content}`, `IsInWorldRequest{bot,name,has_name}`,
  `GetPlayerRequest`, `GetObjectRequest{bot,oid}`, `GetItemInfoRequest`,
  `ListItemsRequest`.
- `GameUpdatePacket` (`proto/mori.proto:260`): mirrors
  `GameUpdatePacket` (`src/protocol/packet.rs`) with `type` (u8 on the wire),
  `object_type/count1(count)/count2/netid/item/flags/float_var/int_data/vec*/particle_rotation/int_x/int_y`.
  `packet_from_proto` (`src/grpc/service.rs:210`) truncates each `u32 → u8`
  and rebuilds flags via `from_bits_retain`.
